# Mapa do Projeto

Este arquivo explica a organização do projeto de forma simples.

## index.html
É a primeira tela da aplicação. Use este arquivo para abrir o sistema.

## menu.html
Arquivo de redirecionamento mantido por segurança. Ele envia para `paginas/menu.html`.

## signup.html
Arquivo de redirecionamento mantido por segurança. Ele envia para `paginas/cadastro.html`.

## paginas/
Aqui ficam as telas que o usuário acessa.

Exemplos:

- `menu.html`: painel principal de acessos.
- `cadastro.html`: tela de criação de conta.
- `ares.html`: painel Ares.
- `estoque.html`: controle de estoque.
- `lista-treinamento.html`: lista de treinamento.
- `lojas-prontas.html`: painel de lojas prontas.
- `perfil.html`: tela de perfil.
- `perfil-lider.html`: tela de perfil do líder.

## estilos/
Aqui podem ficar os arquivos de aparência da aplicação, como cores, fontes, tamanhos e responsividade.

No momento, os estilos principais ainda estão dentro dos arquivos HTML para não quebrar o layout.

## scripts/
Aqui podem ficar os códigos JavaScript da aplicação.

No momento, os scripts principais ainda estão dentro dos arquivos HTML para não quebrar o funcionamento.

## imagens/
Aqui ficam as imagens usadas no sistema.

Subpastas:

- `logos/`: logos principais.
- `icones/`: ícones pequenos, como favicon.
- `banners/`: banners e artes maiores, quando existirem.

## sons/
Aqui ficam os efeitos sonoros usados nos botões, entregas e interações.

## documentos/
Aqui ficam documentos usados para consulta ou download.

Subpastas:

- `pdfs/`: materiais em PDF.
- `modelos/`: cartas e documentos em Word.

## planilhas/
Aqui ficam arquivos Excel usados como controle ou material de apoio.

## apresentacoes/
Aqui ficam arquivos PowerPoint e materiais de apresentação.

## dados/
Aqui podem ficar arquivos JSON ou outros dados locais da aplicação.

## arquivos-antigos/
Aqui devem ficar arquivos antigos, duplicados ou sem uso confirmado.

Nenhum arquivo funcional foi removido nesta organização.
