# Arquivos originais pendentes de substituição

Durante a auditoria, quatro arquivos continham somente uma quebra de linha (`2 bytes`). Eles não eram PDFs ou PowerPoints válidos e, por segurança, deixaram de ser apresentados como downloads funcionais no HUB.

Os bytes originais foram preservados em `arquivos-corrompidos/`:

- `apresentacao-onboard.pptx.original-corrompido`
- `como-criar-anuncio.pdf.original-corrompido`
- `processo-spn-amazon.pdf.original-corrompido`
- `treinamento-fba.pdf.original-corrompido`

## Como substituir

1. Obtenha a versão original e válida do material.
2. Coloque o arquivo no caminho indicado abaixo.
3. Troque o aviso correspondente em `paginas/menu.html` por um link normal.

| Material | Caminho esperado |
|---|---|
| Apresentação Onboard | `apresentacoes/treinamentos/apresentacao-onboard.pptx` |
| Como criar um anúncio | `documentos/pdfs/como-criar-anuncio.pdf` |
| Processo SPN | `documentos/pdfs/processo-spn-amazon.pdf` |
| Treinamento FBA | `documentos/pdfs/treinamento-fba.pdf` |

Nenhum conteúdo foi inventado para substituir os materiais ausentes.
